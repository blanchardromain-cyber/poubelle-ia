Technologie 4° · Collège Saint-Pierre · Les Essarts
⚠️ Votre navigateur ne prend pas en charge le Web Serial. Utilisez Google Chrome ou Microsoft Edge pour piloter la carte Arduino.

1 Charger le modèle d'IA

Autorisez la webcam quand le navigateur le demande. Ne filmez que les objets, jamais les visages.

2 Connecter la carte Arduino déconnectée

⚠️ Fermez d'abord la connexion dans Codecraft : un port série ne peut être utilisé que par un seul logiciel. La carte redémarre à la connexion, la page attend 2 secondes automatiquement.
📡 Mode sans fil : si un shield Bluetooth est appairé à Windows (code 0000 ou 1234), choisissez son port « COM Bluetooth sortant » dans la liste au lieu du port USB — rien d'autre ne change.

3 Réglages de décision

Seuil de confiance 85 %
Stabilité exigée 1,0 s
Pause après action 5,0 s

Chaque classe du modèle est associée à une commande envoyée à l'Arduino ('1' = couvercle jaune, '2' = couvercle marron).
